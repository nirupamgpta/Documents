- **Modern Design**: Clean, professional layout with gradient header
- **Responsive**: Works perfectly on desktop, tablet, and mobile devices

## How to Use

1. **Open the Resume**: Simply open `resume.html` in any web browser
2. **Customize Content**: Edit the HTML file to replace placeholder information with actual details from the LinkedIn profile
3. **Update Styling**: Modify the CSS styles in the `<style>` section to match personal preferences

## Tips for LinkedIn Data Extraction

Since LinkedIn profiles require authentication to access, you'll need to manually extract information:

1. **Personal Info**: Name, headline, location, contact details
2. **Summary**: Professional summary or about section
3. **Experience**: Job titles, companies, dates, descriptions
4. **Education**: Degrees, institutions, graduation dates
5. **Skills**: Technical and soft skills
6. **Certifications**: Professional certifications and dates
7. **Languages**: Language proficiencies
8. **Projects**: Notable projects with descriptions

## Printing

The resume is optimized for printing and will look great on paper. Use your browser's print function (Ctrl+P or Cmd+P) to generate a PDF version.
